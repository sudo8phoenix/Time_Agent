# V2 M01 — planner matching and resolution

Status: `implemented`, `verified_fixture`. Completed 10 October 2026. No user database migration or source schedule edit.

## Changes

- Review search enumerates every executable activity in the report job's pinned schedule, supports IDs, names, project aliases, area, assets, discipline and WBS, and returns pages of 50. The reviewer selects a result and saves an evidenced revision with a reason; UUID editing is unnecessary. Approval and revision validate project, pinned version, active snapshot and leaf eligibility.
- Original candidate JSON and model explanation remain unchanged. The displayed response includes a manually selected activity outside that shortlist; the immutable revision and audit event record the choice, reason and before/after effects.
- Reviewer actions now include existing-activity resolution, request clarification, rejection and missing-schedule-scope flag. Flags close that proposal without creating or mutating schedule activities. Clarification is recorded for follow-up through an amended report/conversation, not an automatically generated schedule row.
- Project alias approvals are immutable, revision-checked snapshots in `AuditEvent`, serialized under the project lock. They are scoped to internal activity identity and project; imported aliases and original schedules remain unchanged. Legacy, graph and conversation matching consume the overlay. The UI supports approval of terminology against the selected activity and a reviewer reason.
- Matching receives discipline and contextual terminology together. A selected activity whose `F<number>` name conflicts with its ID becomes unmatched with `SCHEDULE_LOCATION_CONFLICT`; the conversation exact-area shortcut also excludes such rows. The actual GT10 `SUP-F8-06` / `De-shuttering - F9` conflict is a regression fixture. No identifier normalization merges separate assets.
- Shortlist instrumentation records row count, model calls, selected count and duration. Full-schedule batches remain unchanged; no unmeasured retrieval pruning was introduced.
