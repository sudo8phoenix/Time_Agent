# V2 L01–L03 handoff — 10 October 2026

Status: implemented. L01/L03 fixture and isolated PostgreSQL verified; L02 fixture, integration and live synthetic-model verified.

## Changes

- `schemas/events.py` defines start/finish effects, whole/subactivity scope, evidence and date/minute/second endpoint precision. Date-only endpoints reject times and normalized instants. Local clock times reject timezone suffixes.
- `schemas/observation.py`, extraction prompt v7, `llm/extract.py`, and shared `progress/effects.py` preserve lifecycle observations and construct the same quantity-free effect in the legacy and graph workers. Unresolved assertions produce no actionable effect. Extraction checks endpoint evidence, trusted report-date basis and event-kind agreement. A model-added `Z` suffix is removed only when exact evidence contains the same plain clock time and no timezone, with a warning; other timezone-bearing local times fail validation.
- `db/models.py` and Alembic `0010_lifecycle_precision` add optional endpoint metadata and separate current lifecycle state without changing existing actual dates, quantity events, or the one-observation index.
- `progress/lifecycle.py` recomputes from baseline and active accepted events. It handles exact retries, suspected duplicates, corrections, disagreements, out-of-order input, date precision, timezone uncertainty, known chronological inversion and subactivity isolation. It does not compute physical percentage.
- `docs/api-contract.json` documents lifecycle shapes.
