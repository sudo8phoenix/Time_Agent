## Behaviour implemented

- Added migration `0008_agent_runs`, directly after `0007_activity_embeddings`.
- Added `AgentRun`, `AgentStep`, and `AgentToolCall` SQLAlchemy records with cascading ownership relationships.
- Persisted run graph/state/framework versions, unique checkpoint thread IDs, execution mode, exact lifecycle states, current node, counters, sanitized metadata, hashes, timestamps, durations, and stable errors.
- Added one-run-per-job, thread, run/ordinal, run/node/attempt, and step/tool/attempt uniqueness.
- Added positive ordinal/attempt, nonnegative duration, running-row, state-enum, execution-mode, and error-state checks.
- Added job lookup, ordered-step, and tool-step indexes.
- Added a strict read-only public status contract containing only the §10 response fields. It admits only frozen graph nodes and public UI labels, enforces exact counters, ascending unique step ordinals, state/error rules, and timestamp ordering, and forbids all extra fields.
- No checkpoint, prompt, hidden-reasoning, report-body, secret, raw tool payload, execution-control, URL, lease-token, or path column/API field was added.

## Table and constraint inventory

`agent_runs`:

- Foreign key: `job_id -> jobs.id ON DELETE CASCADE`.
- Unique: `uq_agent_runs_job_id`, `uq_agent_runs_thread_id`.
- Checks: `ck_agent_runs_state`, `ck_agent_runs_execution_mode`, `ck_agent_runs_error_state`.
- Lookup index: `ix_agent_runs_job_id`.

`agent_steps`:

- Foreign key: `run_id -> agent_runs.id ON DELETE CASCADE`.
- Unique: `uq_agent_steps_run_ordinal`, `uq_agent_steps_run_node_attempt`.
- Checks: `ck_agent_steps_ordinal_positive`, `ck_agent_steps_attempt_positive`, `ck_agent_steps_state`, `ck_agent_steps_duration_nonnegative`, `ck_agent_steps_running_unfinished`, `ck_agent_steps_error_state`.
- Ordered lookup index: `ix_agent_steps_run_ordinal`.

`agent_tool_calls`:

- Foreign key: `step_id -> agent_steps.id ON DELETE CASCADE`; this transitively fixes each tool call to exactly one run and prevents orphan/cross-run ownership claims.
- Unique: `uq_agent_tool_calls_attempt` on step/tool/attempt.
- Checks: `ck_agent_tool_calls_attempt_positive`, `ck_agent_tool_calls_state`, `ck_agent_tool_calls_duration_nonnegative`, `ck_agent_tool_calls_running_unfinished`, `ck_agent_tool_calls_error_state`.
- Lookup index: `ix_agent_tool_calls_step_id`.
