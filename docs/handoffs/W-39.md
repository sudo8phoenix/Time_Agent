# W-39 — Graph-only deterministic acceptance

This handoff records the agent acceptance tests after the explicit removal of legacy execution. It describes test evidence only; production worker, settings, API, rollout, and live-smoke changes are owned separately.

The agent acceptance suite now asserts persisted graph outputs against deterministic fixtures. No test imports or calls `app.jobs.pipeline` or compares two execution modes. Generated database identifiers are checked only where the fixture supplies the exact expected value; observation order, proposal candidate order, provenance, effects, warnings, and terminal counts remain asserted directly.
