## Behavior

The component requests `/jobs/{job_id}/agent-run`, validates counters and step bounds, sorts steps by ordinal, and renders only exact public stage labels and bounded counts, attempts, and durations. It ignores internal node names and error fields. Unknown labels are dropped; server and network errors produce fixed UI copy without rendering exception details.

An in-progress run polls every two seconds and stops polling at a terminal run state. A known legacy job renders no graph section and makes no status request. A known graph job retries an initial 404 at two-second intervals up to five retries even if its parent job is already terminal. An unknown-mode terminal job hides the section on 404; an unknown-mode queued/running job retries five times before fixed unavailable copy. Network errors retry while the parent job is active; manual retry and the browser `online` event trigger a fresh request. Abort signals cancel requests when the component unmounts or the job/session changes. A parent job state refresh no longer clears the existing run display.

The section uses existing workspace tokens and a compact responsive layout without adding a nested panel. Playwright assertions cover 390px and 1440px widths, no horizontal overflow, safe public labels, keyboard activation of retry, and stale response behavior after changing jobs.
