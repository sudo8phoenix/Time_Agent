# Regression fixtures

These are small, consumed public/synthetic inputs required by offline tests.
The sealed-measurements captures preserve the original bytes and SHA-256 seals
from historical batch 11, including failed attempts. Annotation files preserve
proposed labels from batches 14/16; only provenance paths were relocated. They
are AI proposals, not independently adjudicated truth or fresh holdout data.
Quality and document corpora exercise deterministic contracts from batches 24/25.

Full run archives, screenshots and handoffs remain local under ignored paths.
Do not regenerate these fixtures by making provider calls during tests.
